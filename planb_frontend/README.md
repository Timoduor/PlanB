# PlanB Frontend (Next.js)

This folder contains the **Next.js frontend** for the PlanB full-stack project.

📌 **For full project setup (backend + frontend), see the root README:**
- [../README.md](../README.md)

---

## Local Development (Frontend Only)

From `planb_frontend/`:

```bash
npm install
npm run dev
```

Then open: http://localhost:3000

---

## Project Notes

- This is a **Next.js App Router** project (`app/` directory).
- When running the full stack, the frontend consumes the backend API at `http://localhost:8000/api`.
